## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze Amazon product sales performance and identify patterns across products, categories, pricing, discounts, ratings, and customer reviews. The dashboard transforms raw product-level data into interactive business insights using data transformation, data modeling, DAX calculations, and interactive visualizations. The goal is to demonstrate how Power BI can be used to convert raw e-commerce data into an analytical decision-support dashboard.

## 💡 Key Analytical Areas
The dashboard provides a consolidated view of Amazon product performance and allows users to explore relationships between:

- Sales and product categories
- Price and sales performance
- Discounts and sales
- Ratings and customer engagement
- Reviews and product popularity

The interactive nature of the dashboard allows users to move from high-level KPIs to more detailed product-level analysis.
